# MAR: Monitoramento de Áreas de Risco (Kotlin)

App para ajudar pescadores a identificar áreas de pesca permitida e a marcar pontos de pesca clandestina e de acúmulo de lixo no mar. O objetivo é promover a sustentabilidade e a proteção dos recursos marinhos.

## Proposta

- **Marcação de áreas:** pesca permitida, zonas de risco e acúmulo de lixo
- **Colaboração:** usuários adicionam e validam novas áreas
- **Notificações:** alertas sobre novas marcações
- **Mapa:** visualização das áreas marcadas

## O que tem hoje

Protótipo de interface (jun–jul/2024) com as telas de login, cadastro e a tela principal com barra superior, texto institucional e contatos. Mapa, banco de dados (Cloud Firestore, previsto) e notificações ainda não foram implementados.

## Stack

- Kotlin, Android SDK 34 (mínimo 24)
- Layouts em XML

## Como rodar

1. Abra a pasta do projeto no Android Studio e aguarde o Gradle sincronizar.
2. Rode em um emulador ou dispositivo Android.
